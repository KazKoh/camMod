barebones MVP camera mod with minimal usage of extra features.

This mod does not use any extra entities, simply teleports the
player where necessary.

The priority and focus was to make an extremely barebones and
lightweight mod that can be expanded upon later. Minimal system impact
was a priority.

Usage is exceedingly simple.

Drop the file "starcammod-1.0.0.jar" into the mods folder
on any neoforge client.
Once the mod is active, when you enter a game with
the respective client,
you may run "/coolCam".
Use "/coolCam Add" to add a camera to the current list.
The camera will be added based on your current position.

Use "/coolCam Del" to remove the latest camera from the list.

Once you are satisfied with your cameras you set up,
type "/coolCam Play" (duration in seconds)

NOTE: Duration is the time in between cameras,
not the whole sequence.

ALSO: Cameras set-ups are persistent. Do not worry about setting them
up over again every time you quit the game.

You may not run this mod anywhere but your own worlds and/or
servers.
